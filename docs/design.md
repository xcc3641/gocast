# Gocast 视觉与交互规格 v1

给实现和贡献者看的界面规格：四块界面（搜索面板、悬浮终端、设置、笔记窗口）长什么样、怎么动、怎么用键盘。改界面的 PR 请对照这份。
实现：MyGo 原生 UI（`ui` 包 + `plugins/glass` + `plugins/sfsymbols` + `plugins/terminal`），**不是 SwiftUI**。所有尺寸单位是 DIP（= macOS 的 pt）。
文案：一律用 copy.md 的字符串，本文出现的中文只是示意，冲突以 copy.md 为准。

---

## 0. 方向一句话

**像系统自带的一块玻璃，安静、紧、全键盘。** 搜索面板一唤出就列出推荐，打字即换成结果（也可以设成只显示搜索栏）；悬浮终端从屏幕顶部落下；设置是一扇普通的 Mac 设置窗口。没有品牌色块、没有插画、没有渐变：Gocast 每天被唤出上百次，任何装饰都会变成噪音。

## 1. 设计令牌

### 1.1 强调色（唯一一个）
- **跟随系统强调色**（`c.Theme().Accent`，MyGo 默认主题已跟随 `Preferences().Accent`）。默认蓝：浅色 `#007AFF` / 深色 `#0A84FF`。
- 理由：启动器是系统级工具，用户在系统设置里选的颜色就是它的颜色，和系统聚焦搜索一致；第一版不需要品牌色。
- 只用在：焦点环、主按钮（保存、关于页的「重新打开」，4.5）、新版本胶囊里的下载图标（4.5）、开关打开态、快捷键录制中的边框、搜索框光标；笔记窗口里：勾上的任务框、编辑区光标、主按钮「新建笔记」「再试一次」（第 11 节）。**结果列表的选中行不用强调色**（见 1.2）。

### 1.2 颜色

| 令牌 | 浅色 | 深色 | 用途 / 对比度 |

| `selection` | `rgba(0,0,0,0.08)` | `rgba(255,255,255,0.10)` | 结果行 / ⌘K 行 / 标签的选中底色（中性灰，不用强调色） |

- 间距基数 4：只用 4 / 8 / 12 / 16 / 20 / 24。

### 1.5 动效
| 动作 | 时长 / 曲线 | 减弱动态效果时 |
|---|---|---|
| 搜索面板出现 | 不动画，立即出现（速度就是体验） | 同 |
| 搜索面板收起 | 立即隐藏 | 同 |
| 紧凑 ↔ 展开（窗口高度变化） | 120 ms，`ui.Smooth` 弹簧（无回弹）；结果在第一帧就已画好，只有窗口底边在动 | 0 ms |
| 选中行移动 | 不动画（瞬移） | 同 |
| ⌘K 菜单出现 | 透明度 0→1 + 缩放 0.97→1，120 ms ease-out，原点右下 | 仅透明度 80 ms |
| 悬浮终端落下（默认位置；其他位置的方向见 3.7） | 透明度 0→1，同时从最终位置上方 12 下移到位，**180 ms ease-out**（cubic 0.2,0.8,0.2,1） | 透明度 0→1，120 ms |
| 悬浮终端收起（同上） | 透明度 1→0，同时上移 8，**120 ms ease-in** | 透明度 1→0，100 ms |

macOS 不让窗口从菜单栏上方滑进来，所以不做整窗从屏幕外落下，改成上面的「淡入 + 下移 12」。位移用 `SetPosition` 按刷新率逐帧推；掉帧就只留透明度（`SetOpacity`），不要两样都没有。

## 2. 屏幕一：搜索面板

### 2.1 窗口
- `Panel: true, Hidden: true, Frameless: true, Transparent: true, Vibrancy: mygo.VibrancyGlass, CornerRadius: 26, DisableResize: true`，宽 **640**（第一版只搜应用和预设、每行很短，和系统聚焦搜索差不多宽）。
- 高度只有两档：**紧凑 66**（只有搜索栏，仅在设置里打开「打开时只显示搜索框」时出现）/ **展开 475**（唤出时默认就是这个，2.5a）（66 搜索栏 + 409 列表；**没有分隔线，没有通栏底栏**，操作胶囊浮在列表上，见 2.4）。无结果状态展开到 **260**（66 + 194）；有计算器卡片时一律 475（2.3a）。高度变化时**顶边不动，只往下长**。
- 位置：鼠标所在显示器，水平居中；**顶边 = 工作区顶 + 工作区高 × 0.20**（让展开后的 475 落在视线中部）。每次唤出都重新计算，不记位置。
- 根视图在玻璃上叠一层底色：浅色 `rgba(246,246,248,0.72)`，深色 `rgba(28,28,30,0.72)`（真机上纯玻璃浅色发灰）。不要再提高透明度到 0.9，那样就没有玻璃感了；对比度靠加深 `textSecondaryOnGlass` 解决。
- `c.Vibrancy()` 为 false 时（旧系统 / 减少透明度）根背景用 `surface`。

### 2.1a 右侧对齐线
搜索面板里所有靠右的东西，右边缘都对在**离面板右边 20** 的同一条竖线上：
- 结果行右侧的「应用 / 预设」：列表左右内边距 8 + 行右内边距 12 = 20。
- 推荐列表（2.5a）右侧的类型标记：同上 = 20。
- 右下操作胶囊里最后一个键帽「K」：胶囊右边距 8 + **胶囊右内边距 12**（原来 6）= 20。
- ⌘K 菜单行右侧的键帽：菜单右边距 8 + 菜单内边距 6 + **行右内边距 6**（左内边距仍 8）= 20；过滤框右内边距也改 6，和键帽对齐。
- 搜索栏右端的转圈：搜索栏右内边距 20。
验收：整面板截图上，这几样的右边缘在同一条竖线上，误差不超过 1 点。

### 2.2 搜索栏（高 66）
- 横向：左内边距 20，Gocast 标志 20（见 1.6），间距 12，输入框撑满，右内边距 20。
- 输入框：`TextInputBase`，20 号，无边框无底色；占位用 copy.md「搜索应用、预设或系统操作」，颜色 `textSecondaryOnGlass`。
- 有输入时右端显示无，**不放清空按钮**（Esc 就是清空）。
- 应用列表还在第一次读取、而用户已经在打字时：输入框右端放 `ui.Spinner` 14×14。

### 2.3 结果列表（展开时，高 409）
- `ui.List`，内边距 上 0、左右 8、**下 52**（最后一行能滚到胶囊上方），行间距 0。列表一直画到窗口底边，从操作胶囊下面滚过。
- 底部渐隐：列表最下面 44 的内容从不透明渐变到 35% 不透明（提示下面还有）。MyGo 做不了遮罩就不做，只靠胶囊盖住，不算缺陷。
- 每行高 **40**，内边距左 10、右 12，圆角 8。横向：图标画框 **26**（行左内边距相应改 10）→ 间距 **10** → 标题（文字起点仍距面板左边 54） → 间距 8 → 副标题（行内，同一行）→ 撑开 → 右侧类型标记。
- 应用图标画框 26 而不是 22：macOS 应用图标自带约 10% 透明边，画 22 实际只看得到 18，偏小；画 26 可见约 21。终端预设的方块图标仍是 22×22，在 26 的格子里居中。
- **运行中的应用**：不做任何标记（不放圆点、不读「正在运行」）。运行与否不影响外观和读屏，也不去取运行列表。
- 副标题：应用**一律不显示**（不显示英文名、不显示所在文件夹如「Applications」，哪怕是靠英文名或拼音搜到的）。**唯一例外**：同一个应用（标识相同）只留一条；名字相同、但确实是不同应用时，在名字后面同一行加副标题区分（13 号 `textSecondaryOnGlass`，和预设副标题同样式、同样的 40% 上限）：先用它的**文件名**（不带 .app，如「Siri AI」）；文件名和显示名一样的那一条不加副标题；几个的文件名也相同时，才写所在文件夹，太长从中间省略。例：「Siri  Siri AI」和「Siri」；终端预设显示 `{文件夹} · {命令}`（copy.md 格式），超长**从中间省略**，保留文件夹最后一段和命令开头，例：`~/Projects/…/my-app · pi`。标题至少保留 160 宽，副标题最多占行宽的 40%（640 宽下行宽 624，约 250）。标题本身超长时尾部省略。
- 右侧类型标记：copy.md 的「应用」/「预设」，12 号，`textSecondaryOnGlass`，右对齐，不加底框。
- **有快捷键的应用 / 预设（2.5b）**：**只在选中时**，类型标记左边多出它的快捷键键帽（通用键帽，2.4 末条：高 20、字 12、底 `keycap`，键帽间距 4），最后一枚键帽和「应用 / 预设」之间 8；类型标记位置不动，仍在 20 对齐线上。没选中的行不显示键帽。搜索结果和推荐列表都一样。理由：列表平时保持安静；要打开它的那一刻正好看到「下次直接按这个」，按几次就记住了。标题省略按选中时的可用宽度算，至少仍留 160。读屏每行都带快捷键（不管选没选中），照 copy.md 11.4。
- 「剪贴板历史」行（copy.md 6.1，搜「剪贴板」「粘贴板」「clipboard」等能找到）：图标同预设方块，符号换成 `doc.on.clipboard`；没有副标题；右侧标记「Gocast」。主操作名「打开」，⌘K 卡片里只有「打开 ↵」一行。↵ / 双击 → 切成剪贴板视图（2.8）。
- 选中行：底色 `selection`，文字颜色不变。**鼠标悬停不改底色、不改光标**；鼠标单击 = 选中，双击 = 打开。
- 一屏约 10 行：上面 9 行完整，最下面一行在渐隐区、被胶囊挡住一部分，提示还能往下滚。滚动条用系统自动隐藏样式。
- 匹配字符**不高亮**（中文拼音匹配时高亮反而对不上字）。

### 2.3a 计算器卡片
搜索框里的文字是算式时（判断规则由解析器定，见需求），结果列表最上面多一张**计算器卡片**：左边算式、右边答案。文字照 copy.md 第 7 节。理由：答案是这时候最要紧的东西，做成比普通行大一号的卡片，一眼就能看到，不用读行。

- 位置：结果列表第一项，在应用和预设前面。卡片上**不放「计算器」标记**，也不加小标题：左右两栏加箭头的样子本身就说明它是计算器；「计算器」只出现在读屏里（copy.md 7.4）。**打开时选中它**（同「第一行选中」）。下面照常是搜索结果，没有分组小标题（打字时的列表一律不加小标题，同 2.5a）。
- 窗口：有卡片时面板一律 **475**，哪怕下面一个搜索结果都没有（这时卡片下面空着，**不出**「没有找到」那两行，也不缩到 260）。理由：边打算式边出现、消失的搜索结果不该让窗口忽高忽低。

### 2.8 剪贴板视图
搜索面板自己切成「剪贴板历史」：左边列表，右边预览。和主搜索同一块玻璃、同一套行、胶囊、键帽、⌘K 卡片，只是更宽、多一栏预览。文字照 copy.md 第 6 节。

#### 2.8.1 进出
- 进入：
  - 剪贴板快捷键（默认 ⌃⌘V）：面板**直接以剪贴板视图出现**，不先出搜索栏。
  - 搜索结果或推荐列表里的「剪贴板历史」行 ↵ / 双击：面板**在同一帧里**换成剪贴板视图。
- 窗口：宽 **760**、高固定 **475**（66 搜索栏 + 409 主体），圆角 26，玻璃和底色同 2.1。从搜索切过来时顶边不动、水平中心不动（左右各长 60），高度直接到 475。不做宽度动画；内容和新尺寸同一帧出现，**不允许空白帧**（同 2.1 的硬要求）。
- 宽 760 的理由：左栏要放得下约 16 个汉字的标题，右栏要放得下一张能看清的图片和一屏文字；640 分两栏后两边都太挤。

- 离开：
  - Esc：有字先清空；没字时，从搜索进来的 → 回到搜索面板空输入的样子（640 宽；平时是推荐列表 475，打开「打开时只显示搜索框」时是 66），推荐列表选中第一行；用快捷键直接打开的 → 收起面板。
  - 视图打开时再按剪贴板快捷键 = 收起面板；按搜索面板快捷键 = 切回搜索面板空输入的样子（同上），不收起。
  - ⌘W 收起；⌘, 打开设置并收起面板。
  - 粘贴 / 拷贝成功后面板立即收起。
- 下次用搜索快捷键唤出时照常是搜索面板（2.6 的 90 秒保留只对搜索面板，不记剪贴板视图）。

## 3. 屏幕二：悬浮终端

### 3.1 形态：默认从屏幕顶部落下（定了；可在设置里换成另外五种位置，见 3.7）
理由：热键终端（iTerm 热键窗口、Ghostty quick terminal）的习惯都是顶部落下；如果也居中浮在屏幕中间，就和搜索面板位置一样，两个快捷键的心智会混（外观统一，位置区分）。顶部落下还让终端和下面的编辑器上下排开，看 pi 输出时下半屏的代码不被挡。

### 3.2 窗口（和搜索面板同一套外观；这是「Gocast」终端外观，默认的「Ghostty」外观见 3.3b）
- 统一原则：悬浮终端和搜索面板看起来必须是同一个程序——**同一种玻璃、同一个底色、同样的圆角、描边、阴影、选中灰、胶囊和键帽**。终端区不再是一块单独的不透明白 / 黑底。
- `Panel: true, Hidden: true, Frameless: true, Transparent: true, Vibrancy: mygo.VibrancyGlass, CornerRadius: 26`（和搜索面板一样 26）。
- 底色：根视图叠 `glassTint`，α = **0.88**。描边和阴影照搬搜索面板：0.5 DIP 描边（浅 `rgba(0,0,0,0.18)` / 深 `rgba(255,255,255,0.18)`）+ 阴影 `0 24 70 rgba(0,0,0,0.30)`（深色 0.55）。
- `c.Vibrancy()` 为 false（减少透明度 / 旧系统）：根背景用不透明的 `#F6F6F8` / `#1C1C1E`，和搜索面板同一规则。
- 尺寸：宽 = 工作区宽 × **宽度设置**（默认 **50%**，范围 30–100%），高 = 工作区高 × **高度设置**（默认 **60%**，范围 30–90%）（80% 太宽；宽度下限 30，否则默认就顶在最左端、没法再调窄）。去掉原来「最宽 1200」的上限——用户自己设了就听用户的。最小 640×300（640 约 77 列，再窄 pi 这类程序的输出会折行），比这小时取最小值。宽度下限跟着屏幕算，见 4.4。
- 位置：鼠标所在显示器，水平居中，顶边 = 工作区顶 + 8（默认「顶部」；其他位置见 3.7）。
- 拖动改大小：底边拖高度；左右两边拖宽度（两边**对称**变化，窗口保持居中）。松手时把新的百分比（四舍五入到整数）写回设置，下次打开就是这个大小。拖动时不做吸附。顶边不能拖。（这是「顶部」的规则；其他位置哪条边不动见 3.7。）
- 跟随当前桌面（Space）；失焦收起默认开，设置里可关（见 4.4）。关掉时窗口仍置顶，但不抢焦点。

### 3.3 布局（自上而下，中间没有分界线）
1. **标签栏** 高 **52**，和搜索栏一样直接画在玻璃上。
2. **终端区**：`terminal.View` 撑满剩余高度，**和标签栏同一块底**——不画分隔线、不换底色。内边距 左右 20（和标签栏左边的标志对齐）、上 0、下 12。
3. 提示和结束信息都改成**浮在终端区上的胶囊**（见 3.6），不再是通栏的条。胶囊出现时终端区下内边距加到 **60**，保证最后一行字和光标不被挡。

### 3.3a 终端颜色（`terminal.Options`；「Gocast」终端外观，「Ghostty」见 3.3b）
- `Transparent: true`：终端不画自己的背景，透出上面的玻璃和底色。`Theme.Background` 仍要给，填不透明的 `#F6F6F8`（浅）/ `#1C1C1E`（深），块光标下的文字用它。
- `Theme` = 下表浅色，`DarkTheme` = 下表深色，跟系统深浅色自动切换（插件已支持）。**不用插件自带的 VS Code 配色。**
- `MinimumContrast: 4.5`：任何程序输出的颜色和底色对比不足 4.5:1 时，插件自动把它调深 / 调亮到刚好够，色相不变。这是 pi 彩色输出在玻璃上看得清的保底，必须开。
- 前景 = `text`（`#1D1D1F` / `#F5F5F7`）。光标 = 系统强调色（和搜索框光标一致），光标下文字 = 背景色。选中 = 系统强调色 α 0.28，选中文字保持原色。搜索高亮用插件默认。
- 字体：SF Mono（`ui.MonospaceFont`），字号取设置（默认 13），行高 1.25。

### 3.3b 终端外观「Ghostty」（默认）
设置 › 悬浮终端「终端外观」有两个选项（copy.md 20）：**Ghostty（默认，更新后所有人都是它）** 和 **Gocast**（就是 3.2–3.3a 原来的磨砂玻璃样子，一点不改）。这一节只写 Ghostty 外观；没写到的尺寸、位置、行为都和 Gocast 外观一样。样张：`images/terminal-ghostty-light.png`（系统浅色模式，带首次打开的提示胶囊）、`images/terminal-ghostty-dark.png`（系统深色模式，按住 ⌘ 的提示）。
理由：目标是看起来和 Ghostty 一样；Ghostty 默认的样子不跟系统浅深色变，所以这里也不变——**浅色、深色模式下整块面板都是同一块深灰**，只有窗口外面的阴影跟着系统变。

- 圆角 26、0.5 DIP 描边 `rgba(255,255,255,0.18)`（浅深色模式都用这个：深灰面板放在浅色桌面上靠阴影分开，放在深色桌面上靠这条亮边分开）。阴影照 3.2：`0 24 70`，浅色模式 `rgba(0,0,0,0.30)`、深色模式 0.55。

- 选中文字：前景和底色互换（白底深字），和 Ghostty 默认一样。

**读用户的 Ghostty 配置（第二步，只在选 Ghostty 时）**
- 读哪里（和 Ghostty 1.3 的 loadDefaultFiles 一样，后读的盖前面的）：`$XDG_CONFIG_HOME/ghostty/config` → 同目录 `config.ghostty`（`XDG_CONFIG_HOME` 没设时是 `~/.config`）→ `~/Library/Application Support/com.mitchellh.ghostty/config` → 同目录 `config.ghostty`。`config-file` 引用的文件在这四个之后按顺序读，路径相对写它的那个文件，前面带 `?` 的找不到就算了；同一文件只读一次（防循环），最多引用 10 层，单个文件超过 1 MB 不读。
- `theme`：名字先找 `$XDG_CONFIG_HOME/ghostty/themes/<名字>`，再找 Ghostty 自带的（`Ghostty.app/Contents/Resources/ghostty/themes`），也可以是绝对路径；`light:X,dark:Y` 两套都读，面板跟着系统浅深色换。先套主题，配置里明写的项再盖上去。
- 只认外观项：font-family（可多个，`""` 清空）、font-size、background、foreground、palette 0–15、cursor-color、cursor-text、cursor-style（block_hollow 当 block）、cursor-style-blink、selection-background/foreground、window-padding-x/y、background-opacity。其他键一律跳过。颜色认 `#rrggbb`、`rrggbb`、`#rgb`，X11 颜色名不认。读不了、写错了都不弹窗：按 Ghostty 默认的样子，读不懂的行跳过。
- 怎么用：配色、光标照配置（没写的用上面 Ghostty 的默认值；选中没写就是前景背景互换）；字体是配置里的字体在前，JetBrains Mono 和 Symbols Nerd Font Mono 跟在后面补字（配置里的字体没装时就是它们）；留白取配置的 window-padding 和 左右 20 / 上 0 / 下 12（胶囊时 60）里较大的；background-opacity 小于 1 时面板底按这个透明度盖在玻璃上（减少透明度时不透明）。面板和标签栏的深浅跟背景色走：背景浅就是浅色的字和灰。
- 什么时候生效：每次唤出终端时看一眼读过的每个文件（含引用和主题，以及没找到的那几个位置）的修改时间和大小，变了就重读；在设置里切到 Ghostty、打开设置时也重读。颜色、字体、留白对所有开着的标签立刻生效，光标样式只对新标签。
- 字号：用户没在 Gocast 里调过字号（settings.json 里没有 fontSize），就用配置的 font-size（限在 11–20），设置里显示的就是这个数；在设置里调过（包括调到 13）就以 Gocast 的为准。老版本把 13 存成「没有」，所以以前选过 13 的用户算「没调过」，会跟 Ghostty 的 font-size 走，直到再调一次——这是分不出来的，接受。没缩放过的标签跟着新字号走，⌘+/⌘- 缩放过的不动。
- 设置里「终端外观」下面的说明见 copy.md 20：没有配置或配置里没有外观项时是默认那句；用上了至少一项时是「字体、配色和光标来自你的 Ghostty 配置。」；有外观项的值用不了（颜色认不出、主题找不到……）时后面加「有几项没认出来，按默认样子显示。」

**切换外观时**
- 在设置里切：开着的终端立刻换（底、标签栏、浮层、颜色、字体一起换），所有标签都换，不用重开；内容、滚动位置不变，行数随行高重新排。光标样式只有新开的标签换（3.3b 和 Gocast 外观都是方块时没有区别）。
- 搜索面板、设置、笔记窗口不受影响，仍跟着系统浅深色走。

**验收（截图）**
1. 系统浅色、深色模式各一张：面板底、标签栏、终端底三处取色都是 `#282C34`，两张一样。
2. 终端第一列字的左边和标签栏标志的左边在同一条竖线上（差不超过 1 点）；最下面一行字不碰圆角。

4. 带图标的提示符（如 Powerlevel10k）图标完整，不出方框或问号。
5. 切到 Gocast 外观后和这次改动前的截图一样。

### 3.5a 按住 ⌘ 显示快捷键提示
按住 ⌘ 不放一会儿，标签上浮出编号键，终端区右下浮出一小块提示，列出终端里能按的快捷键；一松手就没了。字和列表照 copy.md，这里只管样子和时机。

**什么时候出现**
- 悬浮终端是当前窗口，单独按下 ⌘（左右都算，不带 ⇧ ⌃ ⌥，也没有别的键按着），一直按着满 **500 ms** 才出现。理由：⌘C、⌘V、⌘T 这些平时按下到松开一般在 200 ms 以内，500 ms 不会在复制粘贴时闪一下；再长就像没反应。
- 窗口出现时 ⌘ 已经按着（比如用户的唤出快捷键里带 ⌘）：不算，要松开再按。
- 在设置里录快捷键、终端窗口不是当前窗口时：不出现。

**什么时候消失（全部立刻，不等动画）**
- 松开 ⌘。
- 按下任何别的键（字母、数字、方向、Esc…）：提示先消失，这个组合照常生效（⌘2 照常切到第 2 个标签）。之后 ⌘ 还按着也不再出现，要松开再按一次 ⌘ 才重新计时。理由：连续按 ⌘1、⌘2 切标签时提示不来回闪。
- 加按 ⌃ 或 ⌥、鼠标点了任何地方、窗口失焦或收起。
- 例外：加按 ⇧ 不消失（列表里有 ⌘⇧[ / ⌘⇧]，按着 ⌘ 看完再加 ⇧ 是正常用法）；再按 [ 或 ] 就按上一条消失。
- 出现：淡入 120 ms。消失：不做动画，直接没。减弱动态效果：出现也不做动画。

**标签上的编号**
- 前 9 个标签各浮出一枚键帽，只写数字「1」…「9」（⌘ 正按着，不用再写；copy.md 14）。第 10 个起不加。
- 样子：通用键帽（2.4 末条：20×20 正方，圆角 5，底 `keycap`，字 12 `textSecondaryOnGlass`，数字用等宽数字），在标签胶囊里上下居中，右边离标签右边 8。
- 位置就是关闭按钮 × 的位置：提示出现时所有标签的 × 都藏起来，由键帽占那个位置。**标签宽度和标签栏排布都不变**，标题在剩下的宽度里尾部省略（提示消失后恢复原样）。不允许标签在提示出现 / 消失时跳动或换宽度。
- 标签栏横向滚动、有标签在可见区外：那些标签照样有编号，只是看不到；不为了露出编号去滚动。

**提示卡**

### 3.7 出现位置（设置 › 悬浮终端「出现位置」）
只管悬浮终端；搜索面板、笔记窗口不变。字照 copy.md 17。默认「顶部」，和 0.1.8 一模一样（位置、动效、拖边全都不变）。

示意图（六种位置、不动的边、出现方向、设置里那一排位置图）：`images/terminal-positions-light.png`、`images/terminal-positions-dark.png`。

**放在哪儿算**：都在鼠标所在那块屏幕的工作区（扣掉菜单栏和程序坞）里。大小照旧是宽度 / 高度百分比，位置只挪窗口。下表的「8」是离工作区边的距离；窗口比工作区减 16 还宽（或高）时，那个方向的 8 缩成 0，窗口贴满，任何时候都不出工作区。

| 选项 | 位置 |
|---|---|
| 顶部（默认） | 水平居中，顶边 = 工作区顶 + 8（同今天） |
| 中央 | 水平、垂直都居中 |
| 底部 | 水平居中，底边 = 工作区底 − 8（程序坞上面） |
| 左侧 | 垂直居中，左边 = 工作区左 + 8 |
| 右侧 | 垂直居中，右边 = 工作区右 − 8 |
| 鼠标处 | 见下 |

**鼠标处**（每次唤出时算一次，开着以后不跟着鼠标动）：终端里光标所在的那一行落在鼠标处。跑 agent 时光标就在底下的输入框里，所以终端大部分在鼠标上方，抬手就能打字。
1. 光标行：当前标签终端里文字光标所在那一行的竖直中线，从窗口顶边量下来的距离 = 行偏移。终端在后台还活着就用真实的光标行（取后台终端最后一次刷新时的光标位置）。还没开过、刚新建、或光标被程序藏起来的终端没有光标行，按「底部输入栏」估：行偏移 = 窗口高 − 12（底部内边距）− 3.5 × 行高（行高 = 字号 × 当前终端外观的行高：Gocast 1.25、Ghostty 1.0；Gocast 13 号时约 57，也就是倒数第四行，像截图里 agent 输入框下面还有一条线和两行状态那样）。底部有提示胶囊时底部内边距按 60 算。
2. 垂直：顶边 = 鼠标 y − 行偏移，再收进工作区（离上下边各 8）。收进去之后光标行会偏离鼠标，这是唯一允许偏的情况：窗口任何时候都不出工作区，大小也不为它缩。
3. 水平：窗口中线对准鼠标 x，再往里收到离工作区左右各 8（同之前）。不对准光标所在的列：输入框是从左边开始的整条，对准中线就够，而且左右挪动比上下更难预料。
4. 鼠标指针这时压在终端上，落在输入那一行。不另做处理：指针在文字上变成文字光标，开始打字后系统自己把它藏起来。之前定的「离指针下方 24 / 上方 16」和「翻到上方」作废。
5. 读屏、键盘焦点和别的位置一样：出现时焦点在当前标签的终端里。

### 4.5 更新（不弹窗口）
不再用 MyGo 更新插件的窗口，也不用这个插件：直接用 `mygo.Updater.Check(ctx)` 查、`up.Install(ctx, progress)` 下好并换上（MyGo docs/updates.md「Your own update UI」）。整个流程没有任何弹窗；用户能看到的只有四处：搜索面板左下的新版本胶囊、推荐列表里的一行、菜单栏菜单里的一行、关于页按钮下面的一行字。文字照 copy.md 第 12 节。理由：启动器常驻后台，更新这种事不该抢焦点；下好了轻轻告诉一声，不点也会在下次退出时自己换上。

**流程**
- 「自动检查更新」开着（默认）：启动 10 秒后查一次（离上次检查不到 24 小时就跳过，等满 24 小时再查，免得每次重新打开都去查），之后每 24 小时查一次；Mac 睡醒时如果离上次查已超过 24 小时，也查一次。查到新版就直接在后台下载并换好（`Install`），不出任何界面。失败不提示，等下一次。
- 关着：只在用户点「检查更新」（关于页按钮、菜单栏「检查更新…」）时查；查到就直接下载，不再问。
- 「下好了」= `Install` 成功返回。这之后到 Gocast 退出前都是「已就绪」状态：新版本已经放好，Gocast 退出后才换上（macOS 上 MyGo 本来就这样做）。所以不点「重新打开」也没关系，下次退出或重启 Mac 就是新版。
- 点「重新打开」（胶囊、推荐列表那行、菜单栏、关于页按钮，四处同一个动作）→ `mygo.App.Relaunch()`。新版本打开后什么都不提示（不弹「已更新」），和平时开机启动一样，只在菜单栏有图标。
- 查到的版本和已就绪的版本相同就不再下载。已就绪时用户再点检查：照常查，有更新的版本就再下，下好后胶囊和几处文字换成新的版本号。
- 不要的：跳过这个版本、稍后提醒、「以后自动下载并安装更新」勾选框、发布说明正文、下载百分比。想看改了什么，只有关于页的「看看改了什么」链接（打开官网更新记录页并跳到那一版：中文界面 https://gocast.yichenlab.com/zh/changelog/#v{版本}，英文 https://gocast.yichenlab.com/changelog/#v{版本}；{版本} 是下好或正在下的那个）。

## 5. 托盘菜单
系统菜单（`mygo.NewMenu`），文案和顺序照 copy.md 第 1 节；菜单项右侧显示快捷键（`Accelerator`）。不在菜单里画任何自定义视图。新版本下好后，「检查更新…」那一行原地换成「重新打开以更新到 {版本}」；「检查更新…」点了打开设置的关于页并开始检查，不开别的窗口（4.5）。

**保持唤醒**：开着时顶上多三项、没开着时第一组多一个子菜单，见 2.10。

**结束所有终端**（终端在 Gocast 退出后会继续在后台跑，这是唯一能一次性把它们都关掉的地方）
- 位置（copy.md 13）：最后一组，「退出 Gocast」正上方，同一组，中间不加分隔线。顺序：… 分隔线 / 结束所有终端 / 退出 Gocast。理由：两项都是「把东西停掉」，放在一起找得到；离最常用的「搜索…」「悬浮终端」最远，不会在平时点菜单时误点。
- 字照 copy.md 13。不放图标，右侧不放快捷键（系统菜单里其他项也没有图标；这件事用得少，不值得占一个全局键）。
- 什么时候有：有至少一个终端标签时才出现（不管窗口开着还是收起）；一个都没有时整行不出现，菜单和以前一样。不做成灰掉的常驻项：大多数时候它没有意义，灰着只是噪音。菜单每次打开时按当时的标签数决定。
- 点了先确认：系统提醒框（`mygo.Dialog.Message`，`Parent` 留空，显示在屏幕中间；先把 Gocast 切到前台，免得框藏在别的窗口后面）。图标用 App 图标（`Type` 默认），标题、说明、按钮照 copy.md 13；按钮两个：「结束」放在 `DestructiveButtons`（系统画成红字），「取消」是默认按钮（↵ = 取消，Esc = 取消），和 macOS 上会丢东西的确认一样。不加「不再询问」勾选框。理由：这会一下子停掉所有正在跑的命令（开发服务器、长任务），输出也找不回来，而它就挨着「退出 Gocast」。
- 确认后：结束全部会话，后台进程随之退出；终端窗口开着就收起；不出提示。下次唤出 = 第一次唤出（3.6 第一行），用默认预设新开。
- 读屏：系统菜单和系统提醒框自己会读，不另加。
- 不在搜索面板的推荐列表、⌘K 里加这一项，也不在悬浮终端窗口里加。单个标签照旧用 ⌘W 或 exit 关。

## 11. 屏幕四：笔记窗口

一个浮在最上面的小窗口，一次只看一篇笔记，边写边排版，自动保存。和搜索面板、悬浮终端是同一种玻璃，选中灰、卡片、键帽、提示胶囊也都一样（第 8 节：共用一份令牌和组件，不另写）。界面上的字照 copy.md 16。示意图在 `docs/images/notes/`。

### 11.1 入口（搜索面板）
- 三行：笔记 / 新建笔记 / 搜索笔记。行的样子同 2.3「剪贴板历史」那行：图标放在预设同款 22 方块里（圆角 6、底 `keycap`，符号 13 `text`），笔记 `note.text`、新建笔记 `square.and.pencil`、搜索笔记 `doc.text.magnifyingglass`；没有副标题；右侧标记「Gocast」；设了快捷键的，选中时显示键帽（2.3）。
- 主操作名：笔记「打开」、新建笔记「新建」、搜索笔记「打开」（copy.md 16.1）。⌘K 卡片：「{主操作名} ↵」一行，下面是「设置快捷键… / 更改快捷键…」「移除快捷键」两行（2.5），这三条和应用一样能在面板里设快捷键。
- 排序：属于「Gocast 自己的项目」，同分时的先后照 2.9。
- **推荐列表后段（2.5a）**：在「剪贴板历史」后面放一行「笔记」（`note.text`；右侧同别的行：类型标记「Gocast」，设了快捷键的选中时出键帽）。只放「笔记」，不放另外两条：后段是功能目录，一个功能一行；进了窗口按 ⌘N、⌘P 就是另外两条。
- 动作：
  - 笔记：面板收起，笔记窗口出现，显示上次那篇。一篇都没有时给一篇空笔记，光标在第一行，**不先出空状态**（copy.md 16.3）。「笔记」的快捷键：窗口不在最前 → 出现；已在最前 → 收起（同应用快捷键）。
  - 新建笔记：窗口出现，开一篇空笔记，光标在第一行。当前那篇本来就是空的，就直接用它，不再开一篇。
  - 搜索笔记：窗口出现（底下是上次那篇），浏览卡片（11.6）已经打开，光标在卡片的搜索框里。窗口在最前、卡片开着时再按它的快捷键 = 收起窗口。
- **设置 › 快捷键（4.4）**：这三条排在 Gocast 原来三项后面（打开搜索面板 / 显示或收起悬浮终端 / 打开剪贴板历史 / 笔记 / 新建笔记 / 搜索笔记），类型小字「Gocast」，图标同上（20 方块、符号 11）。默认都没设，显示「设置快捷键」；和应用、预设一样可以清掉（×），没有「恢复默认」。
- 一篇空笔记（一个字都没有）不写文件、不进列表。离开它（切到别篇、收起窗口、新建）就当它没存在过。第一次真写了字才建文件夹和文件。

### 11.2 窗口
- `Panel: true, Frameless: true, Transparent: true, Vibrancy: mygo.VibrancyGlass, CornerRadius: 26`。层级同悬浮终端：浮在所有应用上面，跟随当前桌面。底色叠 `glassTint`，α **0.88**（同悬浮终端：要长时间读写文字，厚一点），描边、阴影照 3.2。`c.Vibrancy()` 为 false：不透明 `#F6F6F8` / `#1C1C1E`。
- 尺寸：默认 **560×440**，最小 **360×240**，没有最大。四条边和四个角都能拖着改大小，不吸附。默认 560 的理由：正文 15 号、左右各留 24，一行约 34 个汉字 / 70 个英文字符，是舒服的阅读宽度；440 高能看到十几行，又不挡太多后面的东西。
- 位置：第一次出现在鼠标所在的屏幕，水平居中，顶边 = 工作区顶 + 工作区高 × 0.20（和搜索面板同一条线，从面板里点出来时视线不跳）。之后用户拖到哪、拖多大就记住（退出 Gocast 再开也一样）。记住的位置已经不在任何一块屏幕上（拔了外接屏）时回到默认位置，大小不变；比当前工作区大就缩到工作区以内。
- 拖窗口：按住顶栏空白处拖。双击顶栏不做任何事。
- 出现 / 收起：都不做动画，立即（同搜索面板）。出现时 Gocast 到前台，焦点在编辑区。
- 失焦：**不收起**，留在屏幕上（一边看别的应用一边记）。点它就回到前台。
- 收起：Esc、⌘W、⌘Q（在笔记窗口里 ⌘Q 只收起，不退出 Gocast），或者再按「笔记」的快捷键。收起前先把没存的存完，焦点回到之前的应用。
- Esc 的先后：输入法在组字 → 交给输入法；有卡片开着（浏览 / ⌘K）→ 关卡片；查找条开着 → 关查找条；都没有 → 收起窗口。

- 键：↵ / ⌘G 下一个，⇧↵ / ⇧⌘G 上一个，Esc 关掉查找条，光标落到当前那个匹配上并选中它。
- 只找当前这篇；找所有笔记用 ⌘P。

### 11.5 没能保存
- 写盘失败（copy.md 16.7）：顶栏下面出一块横幅（有查找条时在查找条下面），样子同 2.8.7 提示块：上 4、左右 8，圆角 12，底 `keycap`，内边距上下 10、左右 14；`exclamationmark.triangle.fill` 16 `danger` → 间距 10 → 文字 13 `text`（可以折行）→ 间距 16 → 按钮「再试一次」（2.8.7 主按钮：高 28、圆角 6、左右 12、强调色底白字），上下居中。
- 编辑区往下让，不盖字，照常能写。不自动消失；之后任何一次保存成功（自动的或点按钮的）→ 横幅立即收起，左下出「已保存」（`checkmark.circle` 14）。出现时 `Announce` 读出横幅文字。
- 还没存上就要退出 Gocast：系统提醒框（做法同第 5 节「结束所有终端」），「仍然退出」放 `DestructiveButtons`，「取消」是默认按钮（↵ 和 Esc 都是取消）。

### 11.6 浏览卡片（⌘P）
- 画在窗口里面（同 2.5 ⌘K，不另开窗口），盖在编辑区上面。外观同 ⌘K 卡片：`glass.Glass{}`、圆角 12、阴影 `0 8 24 rgba(0,0,0,0.20)`、1 DIP 描边。出现动画同 1.5 的 ⌘K（原点上方中间）。
- 位置和大小：顶边 = 顶栏底 + 4；宽 = min(窗口宽 − 16, **440**)，在窗口里水平居中；高随内容，最高 = 窗口高 − 56（底下留 8），再多就滚。
- 顶部过滤框：同 2.5（高 36、13 号、左内边距 14、右 12、下面 1 DIP 分隔线），占位 copy.md「搜索笔记」。
- 列表：内边距 6。只有存在置顶笔记时才出两个小标题「已置顶」「最近」（高 26，12 Medium `textSecondaryOnGlass`，字和行里标题左边对齐，垫底，下边距 4）；没有置顶时不出任何小标题。
- 行：高 **44**，圆角 8，左内边距 8、右内边距 6。两行字：标题 13 `text`（空的写「未命名」，用 `textSecondaryOnGlass`）→ 间距 2 → 小字 12 `textSecondaryOnGlass`，写修改时间（copy.md 16.4）。→ 撑开 → 右边：前 9 篇置顶的通用键帽「⌘」「1」…「⌘」「9」（键帽右边在卡片内边距 6 + 行右内边距 6 的线上，同 2.1a 的做法）。标题和小字都尾部省略，键帽永远完整。
- **不放**图标、图钉、「当前」小圆点、删除和置顶按钮（不要：分组标题已经说了置顶，打开时选中的那行就是当前这篇；删除和置顶有快捷键和 ⌘K）。
- 选中 `selection`；单击选中，双击打开；鼠标悬停不变色（同 2.3）。
- 顺序：已置顶（按置顶的先后，最早置顶的是 ⌘1）→ 最近（按修改时间，新的在上）。打开卡片时选中当前这篇，滚到它露出来。
- 搜索：按标题和正文，打字就过滤，选中第一行。结果里有置顶笔记时才分两组、出两个小标题；没有就不出小标题（同上面的规则）。只在正文里命中时，小字换成命中那一句的片段：从命中处往前留约 12 个字，前面截掉的加「…」，尾部省略；这时修改时间挪到右边（12 `textSecondaryOnGlass`，右对齐，占键帽的位置）。标题里命中时小字照旧写时间。打字时不显示 ⌘1–9 键帽（但 ⌘1–9 照样能用）。匹配的字不高亮（同 2.3）。
- 搜不到：列表区高 64，正中一行 copy.md「没有匹配的笔记」13 `textSecondaryOnGlass`。
- 键：↑↓（和 2.7 同几组）移动；↵ 打开（卡片关上，光标回到那篇上次的位置）；⇧⌘P 置顶 / 取消置顶（这一行挪到对应分组，选中跟着它，左下出提示）；⌃X 删除（过滤框是空的时 ⌘⌫ 也算删除；有字时 ⌘⌫ 是删字）；⌘1–9 直接打开第 n 篇置顶；Esc 或再按 ⌘P 关掉卡片，回到原来那篇。
- 在卡片里删了一篇：立即从列表移走，选中移到下一行（删的是最后一行就移到上一行），左下「已移到废纸篓」。删的正好是当前那篇时，关卡片后显示最近列表的第一篇；一篇都没了就是空状态（11.8）。
- 底部**不放**提示条（copy.md 16.4 那一行不用）：这些快捷键都在 ⌘K 菜单里写着。
- 1000 篇也要顺：`ui.List` 只画看得见的行；搜索放到后台，打字不卡。

### 11.7 ⌘K 菜单
- 同 2.5 的卡片（有过滤框，占位「搜索操作…」），宽 **280**（窗口最窄 360，320 会顶到边），锚在右上：右边离窗口右边 8，顶边 = 顶栏底 + 4，动画原点右上。
- 五行（copy.md 16.5 的顺序）：

  | 行 | 图标 | 键帽 |
  |---|---|---|
  | 新建笔记 | `plus` | ⌘N |
  | 浏览笔记 | `list.bullet.rectangle` | ⌘P |
  | 置顶 / 取消置顶 | `pin` / `pin.slash` | ⇧⌘P |
  | 拷贝为 Markdown | `doc.on.doc` | ⇧⌘C |
  | 删除笔记 | `trash`（图标和字都用 `danger`） | ⌃X |

- 「删除笔记」上面加一条 1 DIP `hairline`，上下各留 4。理由：唯一会让笔记离开的一行，和别的隔开，按 ↓ 按过头时眼睛能看到。
- 删除用 **⌃X**，不用 ⌘⌫：编辑区里 ⌘⌫ 是系统的「删到行首」，抢过来会让人一下删掉一整篇。⌃X 和剪贴板历史的删除（2.8）是同一个键。
- 拷贝为 Markdown 用 ⇧⌘C：编辑区的格式快捷键里没有它。
- 当前是空笔记时：置顶、拷贝、删除三行灰掉不能选。
- 删除不确认（copy.md 16.5）：左下出「已移到废纸篓」，窗口里换成最近列表的第一篇；一篇都没有了就是空状态。

### 11.9 键盘
- 窗口：⌘N 新建，⌘P 浏览，⌘K 菜单，⇧⌘P 置顶，⇧⌘C 拷贝为 Markdown，⌃X 删除，⌘1–9 打开第 n 篇置顶，⌘F 查找，⌘+ / ⌘- / ⌘0 字号，Esc / ⌘W / ⌘Q 收起（Esc 的先后见 11.2）。
- 格式（照 brief）：⌘B 粗体、⌘I 斜体、⇧⌘S 删除线、⌘E 行内代码、⌘L 链接、⌥⌘1 / 2 / 3 标题 1 / 2 / 3（已经是这一级就变回正文）、⌥⌘C 代码块、⇧⌘B 引用、⇧⌘7 有序列表、⇧⌘8 无序列表、⇧⌘9 任务列表、⌘↩ 勾任务、Tab / ⇧Tab 缩进、⌘Z / ⇧⌘Z 撤销重做。
- 回车接着列表；空的一项再回车结束列表。选中文字时粘贴网址 = 变成链接。
- 输入法在组字时，上面这些键全部交给输入法（同 2.7，硬要求）。

### 11.10 读屏
- 照 copy.md 16.9。编辑区对读屏是一整块文字，任务框没法单独成为复选框（MyGo 的限制，第一版接受）。补救：⌘↩ 勾 / 取消一项时 `Announce` copy.md 16.9 任务框那一行的字（「待办，已完成」/「待办，未完成」），让读屏用户知道状态变了。
- 顶栏两个按钮、查找条三个按钮都给 `Label`（copy.md）。提示胶囊和「没能保存」横幅出现时 `Announce`。
- 浏览卡片的键帽对读屏隐藏（第 6 节）。

### 11.11 不做的
格式工具栏、/ 菜单、图片、表格、代码高亮、红绿灯、窗口出现和收起的动画、正在编辑的行露出符号、第一行自动变标题样式、浏览列表里的「当前」圆点和行内按钮、拖动排序、最近删除。

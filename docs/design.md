# Gocast 视觉与交互规格 v1

给实现和贡献者看的界面规格：三块界面（搜索面板、悬浮终端、设置）长什么样、怎么动、怎么用键盘。改界面的 PR 请对照这份。
实现：MyGo 原生 UI（`ui` 包 + `plugins/glass` + `plugins/sfsymbols` + `plugins/terminal`），**不是 SwiftUI**。所有尺寸单位是 DIP（= macOS 的 pt）。
文案：一律用 copy.md 的字符串，本文出现的中文只是示意，冲突以 copy.md 为准。

---

## 0. 方向一句话

**像系统自带的一块玻璃，安静、紧、全键盘。** 搜索面板一唤出就列出推荐，打字即换成结果（也可以设成只显示搜索栏）；悬浮终端从屏幕顶部落下；设置是一扇普通的 Mac 设置窗口。没有品牌色块、没有插画、没有渐变：Gocast 每天被唤出上百次，任何装饰都会变成噪音。

## 1. 设计令牌

### 1.1 强调色（唯一一个）
- **跟随系统强调色**（`c.Theme().Accent`，MyGo 默认主题已跟随 `Preferences().Accent`）。默认蓝：浅色 `#007AFF` / 深色 `#0A84FF`。
- 理由：启动器是系统级工具，用户在系统设置里选的颜色就是它的颜色，和系统聚焦搜索一致；第一版不需要品牌色。
- 只用在：焦点环、主按钮（保存、关于页的「重新打开」，4.5）、新版本胶囊里的下载图标（4.5）、开关打开态、快捷键录制中的边框、搜索框光标。**结果列表的选中行不用强调色**（见 1.2）。

### 1.2 颜色

| 令牌 | 浅色 | 深色 | 用途 / 对比度 |
|---|---|---|---|
| `text` | `#1D1D1F` | `#F5F5F7` | 正文、标题、输入文字 |
| `textSecondary` | `#6E6E73` | `#A1A1A6` | 副标题、说明、运行中圆点。在白 5.07:1 / 在 #1C1C1E 6.61:1 |
| `textSecondaryOnGlass` | `#505054` | `#AEAEB2` | 玻璃上的次要文字（搜索面板、终端标签栏）。浅色 #505054 在最差情况（纯黑桌面、选中行）约 4.7:1，留一点余量。深色在 #3A3A3C 上 5.13:1 |
| `selection` | `rgba(0,0,0,0.08)` | `rgba(255,255,255,0.10)` | 结果行 / ⌘K 行 / 标签的选中底色（中性灰，不用强调色） |
| `hairline` | `rgba(0,0,0,0.10)` | `rgba(255,255,255,0.10)` | 分隔线，1 DIP |
| `keycap` | `rgba(0,0,0,0.06)` | `rgba(255,255,255,0.10)` | ⌘K 菜单 / 设置里的按键小方块底色（操作胶囊里的键帽只描边） |
| `surface` | `#FFFFFF` | `#1C1C1E` | 设置内容区、对话框（不透明）；玻璃不可用时的底 |
| `glassTint` | `rgba(246,246,248,α)` | `rgba(28,28,30,α)` | 叠在玻璃上的底色，**搜索面板和悬浮终端共用这一个颜色**。α：搜索面板 0.72，悬浮终端 0.88（终端要长时间读密集文字，厚一点；同色，看起来是同一种材质） |
| `groupFill` | `#F5F5F7` | `#2C2C2E` | 设置里的分组底板 |
| `danger` | `#D70015` | `#FF6961` | 错误文字、删除按钮文字、冲突提示。白底 5.38:1 / 深底 6.03:1 |
| `warning` | `#A05A00` | `#FFB340` | 提示类（文件夹不在、已改在主文件夹打开）。5.31:1 / 9.54:1 |

做法：`t := c.Theme()` 之后只覆盖上表里 MyGo 主题没有或不同的值（`TextMuted` = `textSecondary`、`Danger` = `danger`、`Warning` = `warning`），再 `WithPreferences(c.Preferences())`，保证"增强对比度"仍生效。开启"增强对比度"时：`selection` 透明度 ×1.5，`hairline` 改 0.25。

### 1.4 间距和圆角
- 间距基数 4：只用 4 / 8 / 12 / 16 / 20 / 24。
- 圆角：搜索面板窗口 **26**（macOS 26 玻璃窗的那一档）；悬浮终端窗口 **16**；结果行 / ⌘K 行 **8**；⌘K 菜单 **12**；终端标签 **7**；设置分组 **10**；按钮 / 输入框用 MyGo 主题的 6。
- 图标：结果行图标 **22×22**；⌘K 行图标 16；终端标签内图标 12；侧边栏图标 16。

### 1.5 动效
| 动作 | 时长 / 曲线 | 减弱动态效果时 |
|---|---|---|
| 搜索面板出现 | 不动画，立即出现（速度就是体验） | 同 |
| 搜索面板收起 | 立即隐藏 | 同 |
| 紧凑 ↔ 展开（窗口高度变化） | 120 ms，`ui.Smooth` 弹簧（无回弹）；结果在第一帧就已画好，只有窗口底边在动 | 0 ms |
| 选中行移动 | 不动画（瞬移） | 同 |
| ⌘K 菜单出现 | 透明度 0→1 + 缩放 0.97→1，120 ms ease-out，原点右下 | 仅透明度 80 ms |
| 悬浮终端落下 | 透明度 0→1，同时从最终位置上方 12 下移到位，**180 ms ease-out**（cubic 0.2,0.8,0.2,1） | 透明度 0→1，120 ms |
| 悬浮终端收起 | 透明度 1→0，同时上移 8，**120 ms ease-in** | 透明度 1→0，100 ms |

macOS 不让窗口从菜单栏上方滑进来，所以不做整窗从屏幕外落下，改成上面的「淡入 + 下移 12」。位移用 `SetPosition` 按刷新率逐帧推；掉帧就只留透明度（`SetOpacity`），不要两样都没有。

## 2. 屏幕一：搜索面板

### 2.1 窗口
- `Panel: true, Hidden: true, Frameless: true, Transparent: true, Vibrancy: mygo.VibrancyGlass, CornerRadius: 26, DisableResize: true`，宽 **640**（第一版只搜应用和预设、每行很短，和系统聚焦搜索差不多宽）。
- 高度只有两档：**紧凑 66**（只有搜索栏，仅在设置里打开「打开时只显示搜索框」时出现）/ **展开 475**（唤出时默认就是这个，2.5a）（66 搜索栏 + 409 列表；**没有分隔线，没有通栏底栏**，操作胶囊浮在列表上，见 2.4）。无结果状态展开到 **260**（66 + 194）；有计算器卡片时一律 475（2.3a）。高度变化时**顶边不动，只往下长**。
- 位置：鼠标所在显示器，水平居中；**顶边 = 工作区顶 + 工作区高 × 0.20**（让展开后的 475 落在视线中部）。每次唤出都重新计算，不记位置。
- 根视图在玻璃上叠一层底色：浅色 `rgba(246,246,248,0.72)`，深色 `rgba(28,28,30,0.72)`（真机上纯玻璃浅色发灰）。不要再提高透明度到 0.9，那样就没有玻璃感了；对比度靠加深 `textSecondaryOnGlass` 解决。
- `c.Vibrancy()` 为 false 时（旧系统 / 减少透明度）根背景用 `surface`。

### 2.1a 右侧对齐线
搜索面板里所有靠右的东西，右边缘都对在**离面板右边 20** 的同一条竖线上：
- 结果行右侧的「应用 / 预设」：列表左右内边距 8 + 行右内边距 12 = 20。
- 推荐列表（2.5a）右侧的类型标记和 Gocast 组的键帽：同上 = 20。
- 右下操作胶囊里最后一个键帽「K」：胶囊右边距 8 + **胶囊右内边距 12**（原来 6）= 20。
- ⌘K 菜单行右侧的键帽：菜单右边距 8 + 菜单内边距 6 + **行右内边距 6**（左内边距仍 8）= 20；过滤框右内边距也改 6，和键帽对齐。
- 搜索栏右端的转圈：搜索栏右内边距 20。
验收：整面板截图上，这几样的右边缘在同一条竖线上，误差不超过 1 点。

### 2.2 搜索栏（高 66）
- 横向：左内边距 20，Gocast 标志 20（见 1.6），间距 12，输入框撑满，右内边距 20。
- 输入框：`TextInputBase`，20 号，无边框无底色；占位用 copy.md「搜索应用或终端预设」，颜色 `textSecondaryOnGlass`。
- 有输入时右端显示无，**不放清空按钮**（Esc 就是清空）。
- 应用列表还在第一次读取、而用户已经在打字时：输入框右端放 `ui.Spinner` 14×14。

### 2.3 结果列表（展开时，高 409）
- `ui.List`，内边距 上 0、左右 8、**下 52**（最后一行能滚到胶囊上方），行间距 0。列表一直画到窗口底边，从操作胶囊下面滚过。
- 底部渐隐：列表最下面 44 的内容从不透明渐变到 35% 不透明（提示下面还有）。MyGo 做不了遮罩就不做，只靠胶囊盖住，不算缺陷。
- 每行高 **40**，内边距左 10、右 12，圆角 8。横向：图标画框 **26**（行左内边距相应改 10）→ 间距 **10** → 标题（文字起点仍距面板左边 54） → 间距 8 → 副标题（行内，同一行）→ 撑开 → 右侧类型标记。
- 应用图标画框 26 而不是 22：macOS 应用图标自带约 10% 透明边，画 22 实际只看得到 18，偏小；画 26 可见约 21。终端预设的方块图标仍是 22×22，在 26 的格子里居中。
- **运行中的应用**：图标正下方一个圆点，直径 4，颜色 `textSecondary`，水平与图标中线对齐，圆心在行内 y 35（行高 40，不撑高行）。只在应用行；面板唤出时取一次运行列表，打开期间不刷新。拿运行列表代价高就放到以后的版本。读屏：`Label` =「{名称}，应用，正在运行」（copy.md v1.2），圆点本身对读屏隐藏。
- 副标题：应用**一律不显示**（不显示英文名、不显示所在文件夹如「Applications」，哪怕是靠英文名或拼音搜到的）。**唯一例外**：同一个应用（标识相同）只留一条；名字相同、但确实是不同应用时，在名字后面同一行加副标题区分（13 号 `textSecondaryOnGlass`，和预设副标题同样式、同样的 40% 上限）：先用它的**文件名**（不带 .app，如「Siri AI」）；文件名和显示名一样的那一条不加副标题；几个的文件名也相同时，才写所在文件夹，太长从中间省略。例：「Siri  Siri AI」和「Siri」；终端预设显示 `{文件夹} · {命令}`（copy.md 格式），超长**从中间省略**，保留文件夹最后一段和命令开头，例：`~/Projects/…/my-app · pi`。标题至少保留 160 宽，副标题最多占行宽的 40%（640 宽下行宽 624，约 250）。标题本身超长时尾部省略。
- 右侧类型标记：copy.md 的「应用」/「预设」，12 号，`textSecondaryOnGlass`，右对齐，不加底框。
- **有快捷键的应用 / 预设（2.5b）**：**只在选中时**，类型标记左边多出它的快捷键键帽（通用键帽，2.4 末条：高 20、字 12、底 `keycap`，键帽间距 4），最后一枚键帽和「应用 / 预设」之间 8；类型标记位置不动，仍在 20 对齐线上。没选中的行不显示键帽。搜索结果和推荐列表都一样。理由：列表平时保持安静；要打开它的那一刻正好看到「下次直接按这个」，按几次就记住了。标题省略按选中时的可用宽度算，至少仍留 160。读屏每行都带快捷键（不管选没选中），照 copy.md 11.4。
- 「剪贴板历史」行（copy.md 6.1，搜「剪贴板」「粘贴板」「clipboard」等能找到）：图标同预设方块，符号换成 `doc.on.clipboard`；没有副标题；右侧标记「Gocast」。主操作名「打开」，⌘K 卡片里只有「打开 ↵」一行。↵ / 双击 → 切成剪贴板视图（2.8）。
- 选中行：底色 `selection`，文字颜色不变。**鼠标悬停不改底色、不改光标**；鼠标单击 = 选中，双击 = 打开。
- 一屏约 10 行：上面 9 行完整，最下面一行在渐隐区、被胶囊挡住一部分，提示还能往下滚。滚动条用系统自动隐藏样式。
- 匹配字符**不高亮**（中文拼音匹配时高亮反而对不上字）。

### 2.3a 计算器卡片
搜索框里的文字是算式时（判断规则由解析器定，见需求），结果列表最上面多一张**计算器卡片**：左边算式、右边答案。文字照 copy.md 第 7 节。理由：答案是这时候最要紧的东西，做成比普通行大一号的卡片，一眼就能看到，不用读行。

- 位置：结果列表第一项，在应用和预设前面。卡片上**不放「计算器」标记**，也不加小标题：左右两栏加箭头的样子本身就说明它是计算器；「计算器」只出现在读屏里（copy.md 7.4）。**打开时选中它**（同「第一行选中」）。下面照常是搜索结果，没有分组小标题（打字时的列表一律不加小标题，同 2.5a）。
- 窗口：有卡片时面板一律 **475**，哪怕下面一个搜索结果都没有（这时卡片下面空着，**不出**「没有找到」那两行，也不缩到 260）。理由：边打算式边出现、消失的搜索结果不该让窗口忽高忽低。
- 卡片外形：宽 = 列表宽（640 − 8 − 8 = 624），高 **96**，圆角 **10**，卡片下面留 4 再接第一行结果。底色：没选中 `rgba(0,0,0,0.04)` / 深色 `rgba(255,255,255,0.05)`；选中 `selection`。不加描边、不加阴影（它是列表里的一行，不是浮起来的卡片）。
- 卡片内部：左右两半等宽（各 311.5），正中一条 1 DIP `hairline` 竖线，上下各缩进 14，竖线在中间断开 32（箭头上下各 16 的空），箭头 `arrow.right` 14 Semibold `textSecondaryOnGlass` 放在正中。
- 每一半内容上下左右居中，左右各留 16：
  - 上行（主文字）：左半 = 算式，**20 Regular `text`**；右半 = 答案，**24 Semibold `text`**。答案字大一号、加粗：这时候真正要的是答案。数字用等宽数字（`monospacedDigit`），边打边变时数字不左右跳。
  - 主文字这一行**两边都固定高 30**（不管字号、不管是答案还是说明文字），间距 8，再接小字：这样左右两枚小字永远在同一条水平线上。

- **主体**：内边距 上 12、左右 14、下 14。
  - **按键框**：292 × 56，圆角 8，底色 `rgba(0,0,0,0.04)` / 深色 `rgba(255,255,255,0.05)`（同计算器卡片没选中时），**内描边 2 强调色**（= 正在录，同设置里录制框的录制中）。里面的东西上下左右居中：

  - 只有 ⇧ 或普通键：copy.md「要带上 ⌘、⌥ 或 ⌃…」。
  - 和 Gocast 自己的三个、或别的应用 / 预设撞了：「这个快捷键已用于“{另一项}”。」
  - 系统拒绝注册（别的应用占着）：「这个快捷键已被别的应用占用。如果是在别的启动器里设过…」（两行）。
  再按下一个组合就重新判断；按键框回到 2 强调色只在按下合法的新组合（然后直接存好关掉）或松开后重新按修饰键时。
- **键盘和焦点**：录制时所有按键都给录制（⌘K、↵、↑↓ 也会被当成组合，⌘K 不关卡片）。只有 **Esc** 取消：卡片关上、回到列表（不回到 ⌘K 菜单，不收面板）。点卡片外面 = 取消。面板失去焦点照常收起，录制作废。录制期间 Gocast 自己的三个全局快捷键和所有应用 / 预设快捷键都暂停（同设置里的录制），结束后恢复。搜索框不接收这些按键，不会有输入法组字。
- **按下应用 / 预设的快捷键时**：搜索面板开着就先收起。Gocast 本身不出任何界面（预设除外：悬浮终端照第 3 节出现）。找不到的应用不注册，按了没反应。
- 读屏：卡片 `Label` =「给“{名称}”设快捷键，请按下新的快捷键」；出错、存好的文字用读屏公告读出（copy.md 11.2）。

### 2.8 剪贴板视图
搜索面板自己切成「剪贴板历史」：左边列表，右边预览。和主搜索同一块玻璃、同一套行、胶囊、键帽、⌘K 卡片，只是更宽、多一栏预览。文字照 copy.md 第 6 节。

#### 2.8.1 进出
- 进入：
  - 剪贴板快捷键（默认 ⌃⌘V）：面板**直接以剪贴板视图出现**，不先出搜索栏。
  - 搜索结果或推荐列表（两组都算）里的「剪贴板历史」行 ↵ / 双击：面板**在同一帧里**换成剪贴板视图。
- 窗口：宽 **760**、高固定 **475**（66 搜索栏 + 409 主体），圆角 26，玻璃和底色同 2.1。从搜索切过来时顶边不动、水平中心不动（左右各长 60），高度直接到 475。不做宽度动画；内容和新尺寸同一帧出现，**不允许空白帧**（同 2.1 的硬要求）。
- 宽 760 的理由：左栏要放得下约 16 个汉字的标题，右栏要放得下一张能看清的图片和一屏文字；640 分两栏后两边都太挤。
- 每次进入都是新的：输入清空、筛选回到「全部类型」、选中**最新一条没置顶的**（「今天」或第一个时间分组的第一行），列表滚到最上面；若这一行不在可见范围，滚到刚好露出它。理由：最常见的用法是把刚拷贝的东西再贴一次，置顶的排在上面但不该挡住它。打了字之后选中结果的第一行（同 2.6）；把字删空后回到上面的规则（选中最新一条没置顶的），不是第一行。选中某一组的第一行时，列表滚到连这一组的小标题一起露出来。
- 离开：
  - Esc：有字先清空；没字时，从搜索进来的 → 回到搜索面板空输入的样子（640 宽；平时是推荐列表 475，打开「打开时只显示搜索框」时是 66），推荐列表选中第一行；用快捷键直接打开的 → 收起面板。
  - 视图打开时再按剪贴板快捷键 = 收起面板；按搜索面板快捷键 = 切回搜索面板空输入的样子（同上），不收起。
  - ⌘W 收起；⌘, 打开设置并收起面板。
  - 粘贴 / 拷贝成功后面板立即收起。
- 下次用搜索快捷键唤出时照常是搜索面板（2.6 的 90 秒保留只对搜索面板，不记剪贴板视图）。

## 3. 屏幕二：悬浮终端

### 3.1 形态：从屏幕顶部落下（定了）
理由：热键终端（iTerm 热键窗口、Ghostty quick terminal）的习惯都是顶部落下；如果也居中浮在屏幕中间，就和搜索面板位置一样，两个快捷键的心智会混（外观统一，位置区分）。顶部落下还让终端和下面的编辑器上下排开，看 pi 输出时下半屏的代码不被挡。

### 3.2 窗口（和搜索面板同一套外观）
- 统一原则：悬浮终端和搜索面板看起来必须是同一个程序——**同一种玻璃、同一个底色、同样的圆角、描边、阴影、选中灰、胶囊和键帽**。终端区不再是一块单独的不透明白 / 黑底。
- `Panel: true, Hidden: true, Frameless: true, Transparent: true, Vibrancy: mygo.VibrancyGlass, CornerRadius: 26`（和搜索面板一样 26）。
- 底色：根视图叠 `glassTint`，α = **0.88**。描边和阴影照搬搜索面板：0.5 DIP 描边（浅 `rgba(0,0,0,0.18)` / 深 `rgba(255,255,255,0.18)`）+ 阴影 `0 24 70 rgba(0,0,0,0.30)`（深色 0.55）。
- `c.Vibrancy()` 为 false（减少透明度 / 旧系统）：根背景用不透明的 `#F6F6F8` / `#1C1C1E`，和搜索面板同一规则。
- 尺寸：宽 = 工作区宽 × **宽度设置**（默认 **50%**，范围 30–100%），高 = 工作区高 × **高度设置**（默认 **60%**，范围 30–90%）（80% 太宽；宽度下限 30，否则默认就顶在最左端、没法再调窄）。去掉原来「最宽 1200」的上限——用户自己设了就听用户的。最小 640×300（640 约 77 列，再窄 pi 这类程序的输出会折行），比这小时取最小值。宽度下限跟着屏幕算，见 4.4。
- 位置：鼠标所在显示器，水平居中，顶边 = 工作区顶 + 8。
- 拖动改大小：底边拖高度；左右两边拖宽度（两边**对称**变化，窗口保持居中）。松手时把新的百分比（四舍五入到整数）写回设置，下次打开就是这个大小。拖动时不做吸附。顶边不能拖。
- 跟随当前桌面（Space）；失焦收起默认开，设置里可关（见 4.4）。关掉时窗口仍置顶，但不抢焦点。

### 3.3 布局（自上而下，中间没有分界线）
1. **标签栏** 高 **52**，和搜索栏一样直接画在玻璃上。
2. **终端区**：`terminal.View` 撑满剩余高度，**和标签栏同一块底**——不画分隔线、不换底色。内边距 左右 20（和标签栏左边的标志对齐）、上 0、下 12。
3. 提示和结束信息都改成**浮在终端区上的胶囊**（见 3.6），不再是通栏的条。胶囊出现时终端区下内边距加到 **60**，保证最后一行字和光标不被挡。

### 3.3a 终端颜色（`terminal.Options`）
- `Transparent: true`：终端不画自己的背景，透出上面的玻璃和底色。`Theme.Background` 仍要给，填不透明的 `#F6F6F8`（浅）/ `#1C1C1E`（深），块光标下的文字用它。
- `Theme` = 下表浅色，`DarkTheme` = 下表深色，跟系统深浅色自动切换（插件已支持）。**不用插件自带的 VS Code 配色。**
- `MinimumContrast: 4.5`：任何程序输出的颜色和底色对比不足 4.5:1 时，插件自动把它调深 / 调亮到刚好够，色相不变。这是 pi 彩色输出在玻璃上看得清的保底，必须开。
- 前景 = `text`（`#1D1D1F` / `#F5F5F7`）。光标 = 系统强调色（和搜索框光标一致），光标下文字 = 背景色。选中 = 系统强调色 α 0.28，选中文字保持原色。搜索高亮用插件默认。
- 字体：SF Mono（`ui.MonospaceFont`），字号取设置（默认 13），行高 1.25。

### 4.1 窗口
- 普通窗口（非面板），标题 copy.md「设置」，宽 **820** 高 **580**，不可缩放（原来 720×500；快捷键页要放一整张应用列表，名称、类型、录制框三栏在 820 宽里不挤，580 高一屏约 11 行。其他页只是分组变宽，不另改）；标题栏透明并入内容（MyGo 视图画标题栏，红绿灯保留）。

### 4.5 更新（不弹窗口）
不再用 MyGo 更新插件的窗口，也不用这个插件：直接用 `mygo.Updater.Check(ctx)` 查、`up.Install(ctx, progress)` 下好并换上（MyGo docs/updates.md「Your own update UI」）。整个流程没有任何弹窗；用户能看到的只有四处：搜索面板左下的新版本胶囊、Gocast 组里的一行、菜单栏菜单里的一行、关于页按钮下面的一行字。文字照 copy.md 第 12 节。理由：启动器常驻后台，更新这种事不该抢焦点；下好了轻轻告诉一声，不点也会在下次退出时自己换上。

**流程**
- 「自动检查更新」开着（默认）：启动 10 秒后查一次（离上次检查不到 24 小时就跳过，等满 24 小时再查，免得每次重新打开都去查），之后每 24 小时查一次；Mac 睡醒时如果离上次查已超过 24 小时，也查一次。查到新版就直接在后台下载并换好（`Install`），不出任何界面。失败不提示，等下一次。
- 关着：只在用户点「检查更新」（关于页按钮、菜单栏「检查更新…」）时查；查到就直接下载，不再问。
- 「下好了」= `Install` 成功返回。这之后到 Gocast 退出前都是「已就绪」状态：新版本已经放好，Gocast 退出后才换上（macOS 上 MyGo 本来就这样做）。所以不点「重新打开」也没关系，下次退出或重启 Mac 就是新版。
- 点「重新打开」（胶囊、Gocast 组那行、菜单栏、关于页按钮，四处同一个动作）→ `mygo.App.Relaunch()`。新版本打开后什么都不提示（不弹「已更新」），和平时开机启动一样，只在菜单栏有图标。
- 查到的版本和已就绪的版本相同就不再下载。已就绪时用户再点检查：照常查，有更新的版本就再下，下好后胶囊和几处文字换成新的版本号。
- 不要的：跳过这个版本、稍后提醒、「以后自动下载并安装更新」勾选框、发布说明正文、下载百分比。想看改了什么，只有关于页的「看看改了什么」链接（打开官网更新记录页并跳到那一版：中文界面 https://gocast.yichenlab.com/zh/changelog/#v{版本}，英文 https://gocast.yichenlab.com/changelog/#v{版本}；{版本} 是下好或正在下的那个）。

**新版本胶囊（搜索面板左下角）**
- 什么时候有：已就绪时，搜索面板（推荐列表、搜索结果、计算器都算）每次出现都带着它，不淡出，一直在，直到面板收起。点了右边的 × 就在这次运行里不再出（Gocast 重新打开后自然就没了）。剪贴板视图、悬浮终端里不出；打开了「打开时只显示搜索框」、面板只有 66 高的搜索栏时也不出（那里没有左下角），一展开出结果就出现。
- 位置和外形同提示胶囊（2.4）：左边距 8、下边距 8、高 36、圆角 18、同样的玻璃、描边和阴影。左内边距 14，右内边距 6。
- 内容从左到右：`arrow.down.circle.fill` 14，强调色 → 间距 6 →「新版本 {版本} 已就绪」12 `text` → 间距 10 →「重新打开」按钮 → 间距 2 → 关闭按钮。
  - 「重新打开」按钮：高 24，左右内边距 10，圆角 12，底色 `keycap`，字 12 Medium `text`。按下时底色 `selection` 再叠 0.04 黑（深色叠 0.04 白）。不用强调色写字：强调色蓝在浅色玻璃上只有约 4:1，12 号字不够 4.5:1；强调色只给图标（图形 3:1 就够）。
  - 关闭按钮：24×24，圆角 12，`xmark` 10 Semibold `textSecondaryOnGlass`，按下时底色 `selection`。
  - copy.md 里那个「·」不画出来：按钮自己的底色已经把说明和动作分开了；读屏照 copy.md 读整句（见第 6 节）。
- 宽度：640 宽中文约 256、英文约 280，在最大宽（2.4：窗口宽 − 操作胶囊宽 − 24）以内。万一放不下，只省略「新版本 {版本} 已就绪」那段的尾部，按钮和 × 永远完整。
- 4 秒提示（已拷贝、已设为…、打开失败等，2.4）出现时盖住新版本胶囊：同一位置淡入；4 秒后淡出，新版本胶囊淡入回来（各 150ms，减弱动态效果时直接换）。
- 点「重新打开」：胶囊原地换成 转圈 14 `textSecondaryOnGlass` → 间距 6 →「正在重新打开…」12 `textSecondaryOnGlass`，右内边距改 14，没有按钮和 ×，不可点；面板不收起，直到 Gocast 退出。
- 只用鼠标点；键盘走下面 Gocast 组那一行（面板里的焦点永远在搜索框，不让 Tab 跳到胶囊上）。

**Gocast 组里的一行（推荐列表，2.5a）**
- 已就绪时，「Gocast」组最前面多一行「重新打开以更新到 {版本}」：22 方块里 `arrow.down.circle` 13 `text`（和组里别的行同款，不用强调色），右侧不放键帽。平时没有这一行。
- 打字能搜到（「更新」「重新打开」「update」「relaunch」都算），在搜索结果里右侧标记「Gocast」，同剪贴板历史那行。
- 选中它时操作胶囊主操作写「重新打开 ↵」；⌘K 卡片只有这一行。↵ 或双击 = 重新打开，同时新版本胶囊也换成「正在重新打开…」。
- 不进「推荐」组，也不计打开分数。唤出时默认选中的还是推荐第一行，不因为它变；只有列表里就剩它一行时才选中它。

**菜单栏菜单（第 5 节）**
- 已就绪时，「检查更新…」那一行原地换成「重新打开以更新到 {版本}」，位置不变，不加图标、不加快捷键。点了 = 重新打开。

## 6. 无障碍
- 搜索输入框 `Label` = copy.md 占位文字；列表 `Label(i)` = 「{名称}，{类型}」，预设加「，{文件夹}」；同名应用带副标题的那条读「{名称}，{副标题}，应用」（如「Siri，Siri AI，应用」），正在运行时再加「，正在运行」（copy.md v1.8）。选中变化时 MyGo 列表会通报，不另加。
- 提示胶囊（搜索面板和悬浮终端）出现时用 `Announce` 读出文字。
- 新版本胶囊（4.5）：整枚的 `Label` 照 copy.md 12.1（「新版本 {版本} 已就绪，重新打开，按钮」），关闭按钮 `Label`「关闭」；它常驻，**不** `Announce`（每次唤出都读一遍太吵），只在这次运行里第一次出现时读一次。关于页状态行变化时 `Announce` 读出新的文字（检查中、已是最新、已就绪、失败）。
- 所有只放符号的按钮（新标签、关闭标签、收起、提示胶囊的关闭、录制框）都给 `Label` = copy.md 对应的提示文字。
- 键帽对读屏隐藏（`Hidden` from accessibility），由按钮自身 `KeyShortcuts` 报快捷键。
- 对比度：所有文字 ≥ 4.5:1（见 1.2）。强调色主按钮用系统色，随系统。
- 减少透明度：玻璃自动变成不透明 `surface`（MyGo 已处理），本规格不需要另做。
- 减弱动态效果：见 1.5。
- 剪贴板视图读屏照 copy.md 6.10：列表 `Label`「剪贴板历史」，每行「{标题}，{类型}，{时间}[，已置顶]」，分组小标题读「{名称}，标题」，预览区「预览」，每条信息读「{标签}，{值}」，类型筛选按钮「类型，{当前类型}」。提示块出现时 `Announce` 读标题。缩略图对读屏隐藏（行的 `Label` 已经说了是图片和尺寸）。
- 全部操作都能只用键盘完成；设置窗口 Tab 键顺序 = 侧边栏 → 内容自上而下。

## 8. 实现备注
- 搜索面板高度变化用 `FitContent` + `MaxHeight: 475`（文档 windows.md「Panels」一节），不要自己 `SetSize` 逐帧推；120 ms 的高度过渡如果 FitContent 做不到，就直接跳，**不允许出现空白帧**是硬要求，动画是软要求。
- 选中行底色、键帽、⌘K 菜单都画在面板窗口里，⌘K 不另开窗口（避免焦点离开面板触发 OnBlur 收起）。
- 悬浮终端和搜索面板**共用一份令牌和组件**：`glassTint`、`selection`、`textSecondaryOnGlass`、描边、阴影、提示胶囊、操作胶囊、键帽、弹出菜单。放在一个文件里，两边都引用，不要各写一份——这次两个窗口长得不一样，根子就在各画各的。
- 应用图标用 `Shell.FileIcon`。
